# 发条 · 社交媒体发布控制台

面向小红书图文、国内抖音图文、原生微博和 B站动态的中文工作台。React + TypeScript 提供创作界面，本机 Node.js 服务管理图片文件、SQLite 工作空间数据，以及当前 Chrome 中的平台标签页和发布回执。

## 启动

需要 Node.js 24+ 和 Google Chrome 144+。

```sh
npm install
npm run dev
```

打开 [本地控制台](http://localhost:5173)。默认无需配置文件。可选配置见 `.env.example`；通过 `.env.local` 更换端口或本地数据目录。

```sh
npm run build   # TypeScript 检查与前端构建
npm test        # 数据模型、接口、网页连接器与异常恢复测试
npm start       # 使用 dist 构建，同时提供本地发布接口
```

请启动完整 Node 服务。单独使用 Vite 或静态托管 dist 不提供本地存储、账号连接和发布能力。升级本版本后需重启本项目的 Node 服务，再刷新页面，才能使用新增存储接口。

## 登录自己的账号发布

先打开平时使用的 Chrome，在地址栏输入 `chrome://inspect/#remote-debugging` 并开启远程调试。然后在「平台账号」中点击平台的连接按钮，在 Chrome 授权弹窗中允许连接。无需在命令行启动 Chrome，也不需要安装扩展。Chrome 自身的连接授权和自动化控制提示仍会显示。

四个平台共享这一条 Chrome 连接，各自创建标签页，使用 Chrome 当前登录的账号。小红书统一从创作中心连接和核验登录，避免主站身份接口拒绝请求时误判未登录。重复点击打开会复用本应用创建的已有平台标签页；不会接管你原来打开的网页。原专用配置里的账号不会迁移到日常 Chrome，请在当前 Chrome 登录所需账号并核对。

新建内容，选择平台并添加文案和图片。真实发布前逐个平台核对账号、内容与图片；成功后保存帖子编号、原文链接和发布时间。已经成功的平台不会随其他平台的重试再次发送。结果待核实时请先到平台确认。

可以关闭本应用创建的平台标签页，Chrome 的登录状态保留。账号卡片仍显示“已绑定”和上次核验的昵称、头像，不会因关闭标签页变成未绑定；缓存身份仅用于展示，实际登录状态会在操作前重新核验。下次点击发布会重新连接当前 Chrome、创建该平台标签页并核对实际账号，再显示内容确认页；Chrome 需要保持运行，并可能再次要求授权。所有平台均使用可见标签页，方便完成官网验证。打开控制台和读取账号状态不会自动连接或启动浏览器。

抖音提示“需要本人安全验证”时，在平台标签页完成验证，然后回到控制台点击“核对同一发布请求”。验证由抖音官网处理，控制台不接收短信验证码。保持该标签页和本地服务运行，核对会读取官网随后返回的原请求成功回执，不会再次点击发布。标签页或服务关闭后，尚未确认的记录仍保留防重发保护，不能仅凭 HTTP 200 或空作品列表清除。

小红书和抖音图文要求图片及标题。微博和 B站动态支持文字与图片；标题和正文合并为一段发布内容。当前控制台统一限制每条内容最多 4 张图片，发布时每张不超过 3 MB。普通上传与水印上传均接收不超过 12 MB 的 JPG、PNG、WebP 原图，处理后输出不超过 3 MB 的 PNG；普通 GIF 上传不超过 3 MB 且保留原文件。B站动态接收 JPG、PNG、GIF，本地上传的 WebP 会自动转为 PNG；直接使用 WebP 图片链接时仍需先转换。平台仍会进行自己的校验。

各连接器操作平台官网的编辑器和上传控件，并观察平台返回的发布结果。没有使用开放平台分享接口、第三方签名服务或已归档的 B站 API 库。无需配置 App Key、App Secret 或分享链接。

连接器代码与确定性测试不等于所有账号都已通过真实发布验收。页面变更、账号验证或平台权限可能使自动操作停止。具体使用、会话存储与验收边界见 [平台接入说明](docs/PLATFORMS.md)；微博说明见 [WEIBO.md](docs/WEIBO.md)。

微博头像通过受限的本地图片接口加载，避免浏览器直接读取远程头像被拦截；仅短暂缓存公开图片，加载失败显示占位图。

## 数据与其他功能

- 内容库、草稿、筛选、搜索、卡片/列表、素材管理、手机预览和 JSON 导出。
- 图片上传：编辑器与素材库统一将 JPG、PNG、WebP 转为 PNG，先按原始尺寸无损编码；只有输出超过 3 MB 才逐步缩小尺寸，直至不超过 3 MB。缩小尺寸会损失细节；JPG 转 PNG 不会恢复原 JPG 已丢失的细节。静态原图不超过 12 MB、1600 万像素，宽高均不超过 8192 像素。普通 GIF 原样保存，不转换、不缩小，单张不超过 3 MB。
- 图片水印：编辑器上传图片后点击「图片水印」，可自动生成文字水印（文字可修改）或上传 PNG、JPG、WebP 图标，选择随机位置或九宫格位置，并调整大小与透明度。预览后批量应用，草稿、备份和发布都使用实际带水印的图片；当前编辑期间可重新调整或还原本次水印。素材库勾选「上传时添加水印」或点击「水印设置」即可在上传前设置全部选项，再选择图片预览并确认入库；上传的水印图标、文字、来源、位置、大小、透明度和素材库自动加水印开关会自动保存在本机 SQLite 数据库，图标以独立图片文件保存，素材库与编辑器共用默认设置，刷新或重启浏览器后恢复；取消本次图片处理也会保留已修改的设置。保存失败会显示提示并可重试；清除浏览器站点数据不会删除已保存到本机的设置和图标。水印图标不超过 1 MB，先在原图上合成水印，再按与普通上传相同的 PNG 策略输出；GIF 加水印前请先转换为静态图片。
- 发布按钮实际向所选平台发帖；定时功能目前只记录本地计划，不会自动发送。
- 初始内容仅为示例草稿，不计入已发布或互动统计。旧版模拟已发布记录会转回草稿，真实回执保留。
- 已发布内容可在对应平台回执下修改标题、正文或删除平台原文。文字修改保留原图，平台权限与官网限制仍适用。
- 原数据只能在全部已发布平台确认删除后删除。发布、修改、删除结果待核实时保留原数据；服务端保留操作账本和删除回执。
- 草稿、素材列表、水印设置和删除记录保存在 `.data/library.sqlite`，图片及水印图标保存在 `.data/media/`。相同字节的图片按 SHA-256 去重，记录只保存图片引用；图片不再占用 localStorage，容量取决于本机硬盘空间。保存需收到本地服务确认；窗口间使用版本校验避免过期记录覆盖，列表在聚焦及每 5 秒同步。数据目录可通过 `APP_DATA_DIR` 指定。
- 首次打开新版时，自动迁移当前浏览器旧的 localStorage 素材/草稿及 IndexedDB 水印设置。验证落盘后才清理对应旧数据；迁移失败会保留原数据并支持重试。旧版本中手动添加的远程图片链接仍为远程链接。
- 「导出备份」生成可迁移的工作空间 JSON，包含内容、素材、水印设置和去重的本地图片原始字节；无需依赖原电脑的图片路径。导入支持旧内容备份，保护已发布和已删除记录，分段保存失败时可安全重试。单个 JSON 备份最多 256 MB；更大的工作空间可关闭本地服务后备份 `library.sqlite` 和完整 `media` 目录。不要只复制数据库或在服务写入期间直接复制文件。
- 删除草稿只移除记录，不自动回收图片文件，以保留素材及其他草稿共用图片。完整数据目录还包含平台登录会话，备份工作空间无需包含这些会话目录；媒体仅通过校验后的接口访问，整个 `.data` 不对 HTTP 开放。
- 账号登录信息由日常 Chrome 保管，本应用只在 `.data/{platform}-chrome-connection` 保存连接记忆标记及上次核验的公开账号资料，不复制 Cookie。旧 `.data/{platform}-profile` 原样保留，不会自动接管或删除。发布账本仍位于 `.data/{platform}-publish-ledger.json`。
- 「关闭此平台标签页」只关闭本应用创建的该平台页面；「解除绑定」还会清除连接记忆与账号绑定，不退出 Chrome 中的网站账号。要退出网站账号，请在官网操作。关闭服务只释放应用标签页和调试连接，不退出 Chrome 或关闭原有网页。
- 服务只监听本机回环地址，默认 `http://localhost:5173`，不是公网多用户服务。
- 默认连接已有 Chrome，不启动新浏览器进程，也不添加 `--no-sandbox`。未开启远程调试或未允许连接时，页面显示设置指引，不会自动启动备用独立浏览器。保留的隔离浏览器测试路径启用 Chromium 沙箱。
- 密码在平台官网输入；账号接口不返回 Cookie/token，专用数据目录不对 HTTP 开放。

## 主要文件

- `src/App.tsx`、`src/Composer.tsx`：工作台、编辑、发布核对与回执恢复。
- `src/platforms.ts`：统一平台接口与图片准备。
- `server/index.mjs`：同源本机服务。
- `server/local-storage.mjs`：SQLite 文档、图片文件去重与受控媒体接口。
- `src/local-storage.ts`、`src/local-backup.ts`：浏览器旧数据迁移、异步保存与可移植备份。
- `server/platforms.mjs`：四平台接口、验证、发布去重与持久化回执。
- `server/weibo-browser.mjs`：微博独立会话、二维码和原生微博发布。
- `server/current-chrome.mjs`：复用当前 Chrome 的连接及应用标签页归属管理。
- `server/platform-browser.mjs`：其他平台的标签页生命周期。
- `server/*-adapter.mjs`：小红书、抖音图文和 B站动态的网页流程。
