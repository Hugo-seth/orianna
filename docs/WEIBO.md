# 微博账号直发

## 第一次连接

启动 `npm run dev`，打开平时使用的 Google Chrome 144 或更新版本。在 Chrome 地址栏输入 `chrome://inspect/#remote-debugging`，开启远程调试，再到「平台账号 → 微博」点击连接按钮，在 Chrome 弹窗中允许连接。无需从命令行启动 Chrome 或安装扩展，也不需要注册微博开放平台应用。Chrome 自身的连接授权和自动化控制提示仍会显示。

程序在当前 Chrome 中创建微博标签页，使用 Chrome 当前登录的微博账号。再次打开会复用本应用已有的微博标签页，不接管用户原来打开的网页。未登录时可在该标签页完成账号登录，控制台也会显示可用的官网二维码；二维码过期时刷新，需要手机确认、验证码或官网安全验证时，在这个可见标签页继续。

登录信息由日常 Chrome 保管，本应用只在 `.data/weibo-chrome-connection` 保存连接记忆和上次核验的公开账号资料，不复制 Cookie。旧 `.data/weibo-profile` 原样保留，不会自动迁移、接管或删除；其中的旧账号不会迁移到日常 Chrome，请在当前 Chrome 登录所需账号。微博发布账本仍在 `.data/weibo-publish-ledger.json`。`APP_DATA_DIR` 可调整应用数据目录；该目录包含工作空间、发布记录及可能保留的旧配置，不要提交到 Git、备份到公共位置或共享给他人。

登录后，控制台显示当前账号昵称与 UID。发布前还有一次账号与内容核对；发送前会再次检查实际浏览器账号，账号发生变化时会停止发送。

微博头像通过受限的本地图片接口加载，避免浏览器直接读取远程头像被拦截；仅短暂缓存公开图片，加载失败显示占位图。

## 发文字和图片

选择「微博」平台，标题和正文会以空行合并成一条微博，可以只填写正文。多平台内容逐个平台核对发布，微博结果单独保存。话题无需移除，也不要求附带分享链接。

当前控制台限制 4 张图片，每张不超过 3 MB，支持 JPG、PNG、GIF、WebP。以微博网页实际接受的格式为准。图片来自链接时，会先在控制台浏览器读取；若图片站点不允许跨域，请下载后从本地上传。任何图片无法确认上传完成时，程序都会停止，不会擅自改发纯文字。

「发布到微博 → 确认发布到微博」会向你当前登录的微博账号真实发帖。「模拟发布」已移除；「本地定时计划」目前只保存计划。

可以在连接后关闭本应用创建的微博标签页，Chrome 中的网站登录仍会保留。控制台继续显示“已绑定”和上次核验的昵称、头像，重启本地服务也会保留；缓存身份不代表当前登录已核验。下次点击「发布到微博」，控制台会重新连接当前 Chrome、创建微博标签页并核对实际账号，再展示内容确认页；已有应用标签页会直接复用。Chrome 需要保持运行，并可能再次要求连接授权。确认后、发送前若连接或应用标签页关闭，也会尝试重新连接；必须仍是刚才确认的账号才会继续。

连接失败或登录过期时，文案会保留，界面提示重新连接或登录。未开启远程调试或未允许连接时，程序不会启动备用独立浏览器。遇到验证码或其他安全验证，在 Chrome 的微博标签页按官方提示自行完成，然后返回控制台刷新。程序不会代填验证码或绕过安全验证。

## 关闭与断开连接

- 「关闭此平台标签页」只关闭本应用创建的微博页面，保留 Chrome 登录状态、连接记忆和账号绑定。
- 「解除绑定」还会清除微博连接记忆和账号绑定，不退出 Chrome 中的微博账号，不删除旧专用配置或发布账本。要退出微博账号，请在官网操作。
- 退出本地 Node 服务只释放应用标签页和调试连接，不退出日常 Chrome，也不关闭原有网页。
- 打开控制台或读取账号状态不会自动连接或启动浏览器；连接、登录和发布操作才会按需连接当前 Chrome。

## 发布失败或结果待确认

- **无法连接当前 Chrome**：启动 Chrome，在上述设置页开启远程调试，重试连接并允许 Chrome 的授权弹窗。
- **未登录／账号变化**：在 Chrome 的微博标签页完成登录并刷新账号信息。
- **页面结构变化**：网站更新后可能找不到唯一编辑框或发送按钮，程序会停止。可先在应用创建的微博标签页打开首页，确保编辑框可见；仍失败时需要更新连接器。
- **编辑框已有媒体**：先在微博标签页清空旧媒体，再重试，以免将额外图片发出去。
- **图片上传未完成**：检查微博标签页中的错误；清理本次未完成的媒体后再重试。
- **结果待确认**：请求可能已经提交，先在自己的微博主页核对。相同请求只会查询已有结果，不会再点击发送；不能换请求编号绕过同一内容的未确认记录。

确认成功的回执会带上帖子 ID、实际发布账号、发布时间和原文链接。回执下可修改原微博文字或删除原微博，编辑权限以官网为准，原图片保留。只有全部发布平台都返回明确删除回执后，才能删除控制台原数据。复制为新草稿会生成另一条内容，不代表修改原微博。

## 当前验证范围

以下为此前隔离浏览器模式的历史验收结果，不代表当前复用日常 Chrome 的连接方式已经完成相同的真实账号验收。

已使用独立无头 Chrome 只读验证微博官方二维码，发布编辑器选择器以官网脚本为依据。自动化测试使用模拟页面和回执，覆盖账号变化、图文参数、提交前落盘、超时与重启防重发。2026-09-15 已通过控制台取得真实发布回执；一次删除最终点击后未取得回执，官网只读核对返回目标不存在，控制台仍保留待核对状态。完整验收进展记录在 `output/playwright/lifecycle/ACCEPTANCE.md`。网站改版、账号验证或平台限制仍可能需要进一步适配。
